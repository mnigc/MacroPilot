# MacroPilot — 宏观体制驱动的代币化股票自动调仓智能体

> BNB Hack: 代币化股票专题（16 Sep – 11 Oct 2026）参赛项目
>
> 用一句话说清楚：**用户设定股票篮子，宏观信号决定仓位，智能体在链上自动执行——包括传统券商做不到的周末与隔夜调仓。**

## 为什么是这个项目

代币化股票 7×24 交易，但多数持有者的仓位仍然是"买完就不动"。传统券商的定投/再平衡受限于交易所时间，而链上组合完全可以随宏观环境自动调整。MacroPilot 把宏观研究（流动性、利率、波动率、趋势）转化为离散的**体制状态机**（risk-on / neutral / risk-off），驱动代币化股票篮子的自动再平衡。

对齐官方构建方向：「传统金融-加密投资组合智能体」+「链上与参考价监控」+「一键主题篮子」。

## 架构

```
┌─────────────────────────────────────────────────────────────┐
│  数据层                                                       │
│   FRED CSV（宏观序列）  +  币安 RWA Data API（链上价/参考价/状态）│
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─────────────────────────────────────────────────────────────┐
│  信号层  src/strategy/                                        │
│   流动性(30%) + 利率(20%) + 波动率(30%) + 趋势(20%) → 综合分    │
│   滞回状态机：≥0.6 risk-on / ≤0.3 risk-off / 区间内保持         │
│   输出：目标股票仓位 {risk-on:100%, neutral:60%, risk-off:25%}  │
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─────────────────────────────────────────────────────────────┐
│  回测层  src/backtest/   （先验证再上链）                        │
│   同一套信号跑历史数据 → CAGR / 最大回撤 / 夏普 / 换手 vs 买入持有 │
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─────────────────────────────────────────────────────────────┐
│  执行层  src/exec/                                            │
│   paper：以链上现价纸面成交（默认，零资金风险）                    │
│   live ：quote → approve → EIP-712 签名 → RFQ 下单 → 轮询成交    │
│   护栏：偏离>5pp 才动 / 单笔≥20 USDT / 冲击>1% 中止              │
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─────────────────────────────────────────────────────────────┐
│  展示层  web/   Astro + React + ECharts                       │
│   体制仪表盘 / 持仓与交易记录 / 链上-参考价差监控 / 周末运行证明     │
└─────────────────────────────────────────────────────────────┘
```

## 快速开始

```bash
npm install
cp .env.example .env      # 填入 BINANCE_API_KEY / BINANCE_SECRET_KEY（dev-portal 申请）
npm run smoke             # 连通性验证：拉取代币列表 + 实时价差
npm test                  # 签名与编码单元测试
npm run agent             # 手动触发一轮：信号计算 → 目标仓位 → (paper)执行
```
